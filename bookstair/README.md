# 북스테어 (BookStair)

힐링 북카페 타이쿤 · 스토리텔링 게임.

## 실행

```bash
cd bookstair
npm install
npm run dev     # http://localhost:5173
npm run build   # 타입 체크 + 프로덕션 빌드
npm test        # 로직·콘텐츠 연결 테스트 (vitest)
```

## 기술 스택

- React 18 + TypeScript + Vite
- Tailwind CSS v4 — 우드·베이지·파스텔 팔레트(`@theme`) + 글래스모피즘 패널(`glass`, `glass-strong`)
- Zustand — 게임 상태 + `persist` 로 브라우저 저장
- 매장 화면: SVG 벡터 스프라이트 + 앞쪽 위에서 내려다보는 원근 카메라(`scene/view.ts`)
- 테스트: Vitest (+ jsdom 앱 스모크 테스트)

## 화면 구성

**영업 화면 (전체화면, 처음 켜면 여기)**
- 매장이 화면을 채우고 HUD 가 네 귀퉁이에: 왼쪽 위 주문표 · 오른쪽 위 ⏸ / 🔨 인테리어 / ☰ 메뉴 · 왼쪽 아래 코인 · 오른쪽 아래 남은 영업 시간
- 하루 영업 = 실제 5분. 끝나면 결산 카드(매출 · 계산한 손님 · 놓친 주문 · 새 도감 등록) → 다음 날

**메뉴 화면 (인스타그램형 3단)** — 보는 동안 영업은 멈춤
- 왼쪽 사이드바(모바일은 하단 탭바): 영업하기 · 인테리어(둘 다 영업 화면으로) · 단골·이웃 · 서재 · 상점 · 더 보기
- 상단 스토리 · 가운데 피드 카드(매장 미리보기, 단골 프로필, 손님 도감, 이웃 서점) · 오른쪽 열 · 💌 방명록

## 처음 시작 · 단골 캐스팅

- 빈 8×8 가게 + 보관함(책상 2 · 1인 의자 4 · 커피머신 1)에서 시작. 튜토리얼(안내: 도겸 할아버지): 책상 → 의자 4개 책상에 연결 → 커피머신 → 문 열기 → 첫 음료 → 가게 4레벨까지 키우기 → 처음 온 손님 이야기 듣기 → 취향에 맞는 책장 사서 놓기 → 책 추천으로 첫 단골
- **단골은 캐스팅으로만 생긴다**: 가게가 4레벨이 되면 아직 단골이 아닌 동물 손님이 날마다 한 명씩 "새 손님 ✨"으로 찾아와 취향을 말한다. 맞는 책을 건네면(good 이상) 단골이 되어 매일 오고, 틀리면 그날은 돌아갔다가 다른 날 다시 온다 (`data/guests.ts` 의 `castingEvent`, `guestsForDay`)
- 가구는 메뉴 → 🛍️ 상점에서 코인으로 사서 보관함에 넣는다

## 가게 레벨 · 확장 · 알바

- 손님에게 음료(+8)·책(+10)을 건네거나 단골을 만들면(+40) 가게 경험치가 쌓인다 (사장님·알바 모두). 다음 레벨까지 `20 + 20 × 레벨`, 최고 100레벨 (`systems/level/level.ts`)
- **4레벨**: 동물 단골 후보가 찾아오기 시작
- **매장 확장**: 8×8(1) → 9×8(3) → 10×9(5) → 11×10(10) → 12×10(20) → 13×11(30) → 14×11(50) → 15×12(75) → 16×12(100). 넓어질수록 손님이 자주·많이 오고, 카메라가 물러나 매장 전체를 보여 준다 (`scene/view.ts` 의 `cameraFor`)
- **알바**: 5 · 10 · 50 · 100레벨에 자리가 하나씩 열려 최대 4명. 🧑‍🍳 알바 버튼(메뉴 → 상점)에서 계약금을 내고 고용, 영업이 끝나면 일당을 준다. 알바는 혼자서 주문을 보고 음료를 내려 건네고, 책장에서 책을 찾아 건넨다 — 사장님·다른 알바가 이미 준비 중인 주문은 건너뛴다 (`systems/play/staff.ts`, `data/staff.ts`)
- 예전 10×10 세이브를 열면 1레벨(8×8) 매장 밖에 있던 가구는 보관함으로 돌아간다

## 영업 조작

- 이동: WASD·방향키, 또는 바닥을 눌러 길찾기 이동
- Space(E): 가까운 것 사용 — 커피머신 앞이면 기다리는 주문의 음료 내리기 → 완성되면 들기, 책장 앞이면 부탁받은 장르의 책 찾기, 손님 옆이면 건네기, 단골 옆이면 대화
- 주문표·손님·커피머신·책장을 누르면 그쪽으로 걸어가서 자동으로 사용
- Q: 들고 있는 것 내려놓기 · Esc: 일시정지
- 손님은 기다리는 동안 인내심이 줄어든다. 빨리 건넬수록 팁, 놓치면 시무룩하게 떠나고 평판이 1 내려감

## 폴더 구조

```

  types/        도메인 타입 (content · guest · interior · social · character)
  systems/      React 와 무관한 순수 로직 (+ 테스트)
    interior/grid.ts         배치 검증: 범위·겹침·벽 가구(두 벽)·앞 공간, 이동/회전/보관
    interior/connections.ts  소파↔책상 연결, 좌석·책장 앞·카운터 앞 칸, 메뉴, 경고, 메모판 위치
    guests/                  친밀도·에피소드·큐레이션 판정, 친밀도별 혼잣말
    characters/look.ts       캐릭터 외형 검증·시드 생성, 이동 방향 → 쿼터뷰 방향
    collection/              손님 도감: 방문 기록, 하트 계산
    sim/sim.ts               손님 루프 (입장→책 고르기→[책 요청]→독서→음료 주문→마시기→계산→퇴장), 건네기
    play/                    사장님 이동·충돌·길찾기(player.ts), Space 상호작용 결정(interact.ts), 알바 자동 작업(staff.ts)
    level/level.ts           가게 레벨·경험치, 레벨별 매장 크기, 알바 자리, 레벨업 혜택

  api/          BookstairApi 인터페이스 + 브라우저 저장소 목업 (백엔드 연결 지점)
  data/         콘텐츠: 가구, 단골·대사, 책, 음료, 이웃 서점 목업

  hooks/        useGameLoop (매 프레임 tick + 키보드 입력)
  screens/      PlayScreen(전체화면 영업 + HUD) · CafeView(인스타그램형 메뉴)
  components/
    characters/ CharacterSprite(2등신 SVG: 4방향·자세·행동·표정) · AnimalParts(귀·주둥이·꼬리) · CharacterPortrait
    guests/     GuestProfiles(단골 프로필 · 영입한 독서가) · CustomerCollection(손님 도감)
    layout/     SideNav · StoryBar · RightRail · MessagePill · MoreMenu
    hud/        주문표 · 코인 · 타이머 · 레벨 · 버튼 · 안내 · 일시정지 · 결산
    staff/      StaffPanel(알바 고용 · 자리 잠금)
    shop/       ShopScene(영업+인테리어 편집) · StorePreview · InteriorPanel · scene/(카메라·상자·가구·방·캐릭터·커피머신 진행 표시)
```

## 핵심 규칙

- **필수 배치 규칙** (어기면 배치 불가): 매장 범위, 겹침, 벽 가구는 오른쪽 벽(맨 윗줄) 또는 왼쪽 벽(맨 왼줄), 책장·커피머신 앞 1칸 비우기
- **연결 규칙** (배치는 되지만 경고): 소파·의자가 바라보는 방향 바로 앞에 책상이 닿아야 세트가 되고, 연결된 좌석에만 손님이 앉음
- 배치한 **책장**이 큐레이션 도서와 손님이 책 고르는 자리를, **커피머신**이 메뉴와 계산대 자리를 결정
- 인테리어 편집 중·이웃 서점 방문 중에는 영업이 일시정지

## 캐릭터

- **단골은 동물, 일반 손님은 사람**: 단골 서윤(다람쥐)·도겸 할아버지(곰)·하린(고양이), 동물은 9종(고양이·강아지·토끼·곰·다람쥐·여우·생쥐·양·부엉이)을 그릴 수 있음
- 외형은 데이터(`CharacterLook`: 종·털/피부·머리·상의·하의·소품·소품 색)로 정의하고 한 컴포넌트가 그림
- 4방향(앞·뒤 × 왼·오른) · 자세(서기·걷기·앉기) · 행동(독서·음료·스케치·책 고르기·계산) · 표정(기본·기쁨·슬픔·놀람·수줍음·몰입)
- 단골: 성격 키워드·소개·앉았을 때의 버릇·친밀도별 혼잣말(`data/guests.ts`), 대화 중 대사 감정에 따라 얼굴이 바뀜
- 일반 손님은 12가지 유형(`data/customers.ts`, 예: 시험기간 고3·야근 개발자). 좋아하는 음료가 메뉴에 있으면 그걸 주문
- **손님 도감**: 처음 계산하고 나간 유형이 등록되고, 방문 1·3·6·10·15번마다 하트가 하나씩 참 (단골·이웃 탭)
- 예전 세이브·공유 링크의 독서가는 id 로 외형을 채움

## 인테리어 조작

- 가구를 끌어서 이동(격자 스냅), 보관함 가구를 끌어다 배치
- 우클릭 메뉴: 회전 · 이동 · 보관 / 단축키 R 회전 · Del 보관 · Esc 취소

## 아직 서버가 없어서

- 방명록·이웃 서점은 `api/bookstairApi.ts` 의 **로컬 목업**(이 브라우저에만 저장)
- 내 서점 공유 링크는 배치를 URL 에 담아 보내므로 상대가 구경은 할 수 있지만, 남긴 방명록은 상대 브라우저에만 저장됨
- 백엔드를 붙일 때는 `BookstairApi` 를 fetch 로 구현해 `api` 만 바꾸면 됨
